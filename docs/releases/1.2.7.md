# CountAway 1.2.7 — Internal upgrade candidate

**Pre-release validation copy. Not a published release.**

This candidate packages the widget layout fixes currently implemented on the 1.2.7 workstream so their in-place upgrade behavior can be checked without waiting for the rest of the widget redesign.

## Changes in this candidate

- Improve background and rounded-corner scaling on both widget families.
- Make widget size and orientation handling more reliable, including previews.
- Avoid stranded word fragments in narrow, tall day-count widgets while protecting event icons and signed counters.
- Keep the two existing widget providers and stored widget settings unchanged.

This candidate does **not** yet include the proposed 2×2/3×2 visual designs or an optional Days + hours mode.

**Upgrade safety:** Only install over an existing 1.2.6 installation when the candidate APK signing certificate matches the installed application. Do not uninstall or remove widgets to make an incompatible package install. The eventual public 1.2.7 build must use a versionCode greater than this test candidate's 16 for devices that install it.
