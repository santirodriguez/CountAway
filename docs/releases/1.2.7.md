# CountAway 1.2.7

Add and preview widgets directly from an event on Home.

- **Days Card** counts calendar days until or since a date. A larger widget has room for the date.
- **Days + hours** shows approximate days and hours, with the event date below.
- **Only hours** uses a live timer for shorter intervals and shows the total in hours for long intervals.
- **Full counter** breaks down time into years, months, days, hours and minutes, with the event date below.

Timed snapshots refresh periodically. TalkBack also reads the last calculation time.

Reopen widget setup to edit an existing widget in place. The preview shows how the selected format looks, and the setup screen explains how to resize it from your launcher.
