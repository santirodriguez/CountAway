# CountAway 1.2.7

Add and preview your widgets right from Home. Open an event’s widget action to choose Days Card or Time Detail and see how each style looks before adding it.

- **Days Card** gives the day count more room and shows the start date when the widget has enough space.
- **Time Detail** keeps the live counter prominent and displays the date and time zone on separate lines in expanded layouts. Events without a time can open the editor from widget setup.
- **Widget setup** lets you reopen the configuration for an existing widget and includes a tip for resizing it from the launcher.
