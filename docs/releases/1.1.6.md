# CountAway 1.1.6

CountAway 1.1.6 adds a few useful things without developing an urgent need to become a calendar suite.

## New

- Follow the system theme, alongside the existing Light and Dark appearances.
- Share a countdown through Android's regular share sheet.

## Improved

- Make selected languages, event types, and custom icons clearer to accessibility services.
- Give the 3 · 2 · 1 · 0 countdown states proper accessible descriptions while keeping their existing visual style.
- Give every countdown a collision-safe notification identity.
- Update the F-Droid documentation so it describes the workflow instead of freezing one particular release in time.

No new permissions, accounts, network access, analytics, or dependencies.
