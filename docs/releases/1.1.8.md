# CountAway 1.1.8

CountAway 1.1.8 learns that birthdays have an annoying habit of coming back every year, while tightening reminder and backup reliability.

## New

- Countdowns can now repeat yearly across the app, widgets, native sharing, backups, and reminders.
- Yearly countdowns automatically move to their next occurrence, including February 29 falling back to February 28 in non-leap years.

## Improved

- Pending reminders are rescheduled when Android notification blocking is removed.
- Backup import confirmation now applies to the exact validated snapshot that will be restored.
- One-time past events keep their existing elapsed-day behavior.

No new permissions, accounts, network access, analytics, or runtime dependencies.
