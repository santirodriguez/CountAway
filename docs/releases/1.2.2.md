# CountAway 1.2.2

Count the days in either direction.

Events can now count down to a future date or count up from a start date. Count-up events use the same local event list, fixed widgets, sharing, and backup format, while **Next countdown** remains dedicated to upcoming count-down events. Recurrence and reminders stay intentionally limited to count-down events.

Language switching is now explicit and accessible: choose English, Español, or Català from the app, or return to the System language. The chooser preserves unsaved work and refreshes app, widget, and notification-facing language state without adding any network dependency.

This release also hardens widget pin callbacks across Android versions, improves large-text widget layouts, and uses neutral event wording on surfaces shared by both count directions.

Home is more compact and easier to scan: the day-count tile takes less room, event titles get more breathing room, and the edge actions use a cleaner three-dot notch with a polished contextual menu that puts **Add widget** first. Confirmations and pickers now share the same CountAway visual language, with clearer destructive actions in both light and dark themes.

Existing data is migrated automatically to storage schema 7. No new permissions, Internet access, accounts, analytics, cloud sync, or runtime dependencies.

VersionCode 11; Android 8+ (API 26); target/compile SDK 36; backup schema 7.
