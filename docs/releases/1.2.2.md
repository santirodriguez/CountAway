# CountAway 1.2.2

Count the days in either direction.

CountAway can now count down to a future date or count up from a start date. Fixed widgets support both directions, while **Next countdown** keeps following the nearest upcoming count-down event.

Home is cleaner and easier to scan, with more compact count tiles, clearer groups, more room for event titles, and polished event actions and dialogs.

Language switching is now explicit for English, Español, and Català, with a System option. Widget pinning and large-text layouts are also more reliable.

Existing data migrates automatically to storage schema 7. Count-up events do not repeat or use reminders.

VersionCode 11; Android 8+ (API 26); target/compile SDK 36; backup schema 7.
