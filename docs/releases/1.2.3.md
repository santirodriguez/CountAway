# CountAway 1.2.3

CountAway 1.2.3 prepares the same lightweight app for Google Play without replacing its existing GitHub, Obtainium, or F-Droid distribution.

The release centralizes the supported-language catalog and adds translation validation/contributor guidance. English, Español, and Català remain the enabled languages, with script-aware locale matching ready for future additions.

Release validation now upgrades from the published 1.2.2 build. Privacy and Play preparation documentation also reflect both count-down and count-up events and the signing/asset/declaration gates required before an actual Play submission.

VersionCode 12; Android 8+ (API 26); target/compile SDK 36; backup schema 7.
