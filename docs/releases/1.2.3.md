# CountAway 1.2.3

CountAway 1.2.3 prepares the same lightweight app for Google Play without replacing its existing GitHub, Obtainium, or F-Droid distribution.

The release centralizes the supported-language catalog and adds translation validation/contributor guidance so future language contributions can stay focused on linguistic work. English, Español, and Català remain the enabled languages. Script-aware matching is in place for future additions, but Simplified Chinese is not advertised or packaged unless a complete current contribution passes native review and release acceptance.

Release validation now upgrades from the published 1.2.2 build. Privacy and Play preparation documentation also reflect both count-down and count-up events and the signing/asset/declaration gates required before an actual Play submission.

No new runtime permissions, Internet access, account system, ads, analytics, native code, or storage-schema migration.

VersionCode 12; Android 8+ (API 26); target/compile SDK 36; backup schema 7.
