# CountAway 1.2.0

CountAway 1.2.0 makes widgets faster to add, easier to style, and more visually consistent while preserving the app's lightweight local-only model.

## New

- Long-press a saved countdown to open a focused widget setup screen before Android's pin confirmation.
- Choose the widget background and System, Light, or Dark appearance with a live preview.
- CountAway remembers the last style you chose for the next new widget without changing widgets that are already configured.

## Improved

- The countdown editor is focused on the countdown again; widget creation no longer adds management buttons to that screen.
- Existing placed widgets keep Android's native reconfiguration path on launchers that expose it.
- Ridge uses a proportional chevron treatment that scales cleanly across Compact, Short, Standard, and Large widget layouts.
- Every widget style has a tuned Light/Dark palette with stronger text contrast.
- Widget setup, generic picker configuration, pin previews, and installed widgets share the same production layouts and presentation rules.
- Large-text handling prioritizes the countdown value and removes optional detail before the essential count becomes cramped.
- Pinning callbacks preserve the exact event/style snapshot requested and avoid overwriting an already configured widget.

## Release integrity

- Version 1.2.0 remains versionCode 9, JSON schema 5, minSdk 26, target/compile SDK 36, and the historical signing identity.
- No new runtime dependencies, Internet permission, accounts, analytics, cloud sync, native libraries, exact alarms, foreground services, or permanent services.
- Release preparation can remain on the exact version-matched `release/1.2.0` branch through publication, with stale-head, tag-lineage, signing, reproducibility, permission, runtime-dependency, R8, and F-Droid gates preserved.
