# CountAway 1.2.0

CountAway 1.2.0 makes widgets faster to set up, adds more recurrence options, improves visual polish, and fixes several reliability details while keeping the app fully local and lightweight.

## Highlights

- Long-press a saved countdown to open a focused widget setup screen for that exact event.
- Choose any of the nine widget styles, pick System, Light, or Dark appearance, preview the result, and add it directly to the Home screen.
- Repeat countdowns weekly, monthly, or yearly, with sensible handling for shorter months and clear next-occurrence information.
- Recurring reminders continue rolling forward instead of stopping after the first occurrence.

## Improved

- Direct widget pinning and reconfiguration are more resilient across Android launchers while preserving each widget's selected countdown and style.
- Daily widget refreshes now advance reliably without requiring CountAway to be reopened.
- Classic, Mist, Horizon, and Sunset received visual refinements while preserving the accepted identities of the other widget styles.
- Widget previews and installed widgets now share more consistent presentation rules across Compact, Short, Standard, and Large sizes.
- Large-text layouts prioritize the countdown value and reduce optional detail before the essential information becomes cramped.
- Help is cleaner and easier to read, with redundant introductory copy removed.

## Compatibility

- Existing countdown data, reminders, widget configurations, backups, and the JSON schema remain compatible.
- Version 1.2.0 remains versionCode 9, minSdk 26, and target/compile SDK 36.
- No new runtime dependencies, Internet permission, accounts, analytics, cloud sync, native libraries, exact alarms, foreground services, or permanent services.
