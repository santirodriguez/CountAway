# CountAway 1.2.0

CountAway 1.2.0 gives widgets a much more direct setup flow, stronger visual identity, weekly/monthly/yearly recurrence, and safer real-launcher pinning while preserving the app's lightweight local-only model.

## New

- Long-press a saved countdown to open a focused setup screen for that exact event.
- Choose from all nine backgrounds in a visual style grid, pick System, Light, or Dark appearance, and preview the result before adding it to the Home screen.
- CountAway remembers the last style that was successfully used for a new widget without changing widgets that are already configured.

## New recurrence options

- Repeat countdowns weekly, monthly, or yearly without changing the existing JSON schema.
- Monthly recurrence keeps the original day when possible and uses the last valid day in shorter months before returning to the anchor day.
- Recurrence is visible in the countdown list and editor, including the next occurrence and an explanatory short-month note when relevant.
- Recurring reminders roll forward after delivery or a missed/exhausted attempt instead of stopping after the first recurrence.

## Improved

- Direct pinning now preserves the exact selected countdown/style and can reconcile a newly created launcher widget even when the optional Android success callback is delayed or unreliable.
- Scheduled daily widget refreshes now reach the refresh receiver, so placed widgets keep advancing without requiring the app to be reopened.
- The countdown editor stays focused on countdown editing; widget creation no longer adds management controls to that screen.
- Classic Light uses a softer neutral white; Mist gains restrained fog bands; Horizon reads as a clearer day/night horizon; Sunset gains a low setting sun and warm haze; Ember keeps its warmer spark/flame treatment. Accepted Forest, Pulse, Breeze, and Ridge artwork remains unchanged.
- Help keeps the large-text-safe three-step cards, removes the redundant explanatory paragraph, and turns the Step 3 calendar mascot into a progressive 1/3/7/10/20/50/100-tap easter egg.
- Existing placed widgets keep Android's native reconfiguration path on launchers that expose it.
- Widget setup, generic picker configuration, pin previews, and installed widgets share the same production layouts and presentation rules; setup/configuration previews also state the selected style and appearance explicitly.
- Large-text handling prioritizes the countdown value and removes optional detail before the essential count becomes cramped.

## Release integrity

- Version 1.2.0 remains versionCode 9, JSON schema 5, minSdk 26, target/compile SDK 36, and the historical signing identity.
- No new runtime dependencies, Internet permission, accounts, analytics, cloud sync, native libraries, exact alarms, foreground services, or permanent services.
- The supplied artwork references remain documentation assets; runtime widget artwork is rendered natively so the release stays lightweight.
- Release preparation can remain on the exact version-matched `release/1.2.0` branch through publication, with stale-head, tag-lineage, signing, reproducibility, permission, runtime-dependency, R8, and F-Droid gates preserved.
