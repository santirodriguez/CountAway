# CountAway 1.2.0

CountAway 1.2.0 makes widgets faster to add, easier to tune, and more visually consistent while preserving the app's lightweight local-only model.

## New

- Choose default background and System, Light, or Dark appearance for newly configured widgets.
- Long-press a saved countdown to request its widget directly on launchers that support Android widget pinning.
- Open Widget settings from a saved countdown to edit one or choose among multiple existing fixed widgets.

## Improved

- Ridge now uses a proportional chevron treatment that scales cleanly across Compact, Short, Standard, and Large widgets.
- Every widget style has a tuned Light/Dark palette with stronger text contrast.
- Configuration, defaults, pin previews, and installed widgets share the same production layouts and presentation rules.
- Large-text handling prioritizes the countdown value and removes optional detail before the essential count becomes cramped.
- Quick-pinning callbacks preserve the exact event/style snapshot requested and avoid overwriting an already configured widget.

## Release integrity

- Version 1.2.0 remains versionCode 9, JSON schema 5, minSdk 26, target/compile SDK 36, and the historical signing identity.
- No new runtime dependencies, Internet permission, accounts, analytics, cloud sync, native libraries, exact alarms, foreground services, or permanent services.
- Release preparation can remain on the exact version-matched `release/1.2.0` branch through publication, with stale-head, tag-lineage, signing, reproducibility, permission, runtime-dependency, R8, and F-Droid gates preserved.
