# CountAway 1.2.1

A small fix for the things you are looking forward to.

Narrow, tall widgets now use their available height to wrap event titles and show their icons again. The birthday cake no longer disappears simply because a widget is narrow. Compact layouts still protect the count when space is genuinely limited, and configuration previews follow the same sizing rules.

This update also adds Android rendering checks that verify titles, emoji, icons and counts together, including larger text. Upgrade validation now starts from the published 1.2.0 release.

No new features, permissions or runtime dependencies. Existing countdowns, reminders, widgets and backups keep the same format and behavior. Everything stays on your device.

VersionCode 10; Android 8+ (API 26); target/compile SDK 36; backup schema 6.
