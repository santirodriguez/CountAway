# CountAway 1.2.6

**A fresh start, with a safety net.**

Some counters are meant to start again. CountAway now lets you reset an eligible date-only count-up to today from its Home menu, with confirmation and Undo.

## What's new

- **Reset to today:** restart a reusable date-only count-up without recreating the event. Timed or recurring events still use the editor.
- **Optional automatic backups:** enable verified JSON copies of your events in About. On Android 10+, the default location is Downloads/CountAway; you can choose another folder. Older Android versions require folder selection.
- **Keep a recoverable copy:** CountAway manages seven distinct verified snapshots when the provider allows safe cleanup. Existing manual Import restores your events from a saved JSON file.
- **Clearer destination status:** see where copies go and whether a backup or folder change needs attention.

Automatic backups are off until you choose to enable them. JSON files contain event details, but not app settings or launcher widget placement. Backups run on Android's best-effort schedule, not at an exact time.
