# CountAway 1.2.4

**⏱️ Dates have hours now.** Some moments deserve more than a day count.

Add an optional time to any event and watch **hours, minutes, and seconds tick live on Home**. Prefer the classic experience? Leave the time blank—your day counts still work just as before.

## ✨ What's new

- 🕒 **Every second counts.** Optional times for countdowns and count-ups, with live time details on Home.
- 🧩 **Meet the live-hours widget.** A dedicated home-screen widget for events with a time, alongside your classic day-count widgets.
- 📐 **Made to fit.** Widgets adapt to their space; distant dates can show days and a running clock when there's room.
- ⚡ **Little improvements, big difference.** More responsive local backups, steadier widget updates, clearer large-text actions, and better handling of extra-long event titles.
