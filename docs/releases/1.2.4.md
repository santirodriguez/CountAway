# CountAway 1.2.4

**Dates have hours now.**

Add an optional time to an event to see live hours, minutes, and seconds on Home. Leave the time blank, and CountAway still counts calendar days as before.

## What's new

- **Optional event times.** Count down or count up with live time details.
- **A dedicated live-hours widget.** Designed specifically for events with a time, alongside the original day-count widgets.
- **Responsive at a glance.** The new widget adapts to its available space; distant dates can show days and a running clock when space allows.
- **Smoother everyday use.** More responsive local backups, resilient widget refreshes, clearer large-text actions, and safer handling of unusually long historical event titles.
