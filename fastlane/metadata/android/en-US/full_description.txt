CountAway keeps important dates simple and visible on your home screen.

Create multiple local events and choose whether each one counts down to a future date or counts up from a start date. Pick an event type or custom icon and add compact or resizable widgets. Fixed widgets support both count directions, while Next countdown automatically follows your nearest upcoming count-down event.

Add an optional time to an event for live hours, minutes and seconds on Home. A dedicated live-hours widget is designed specifically for timed events, alongside the classic day-count widgets. For distant dates, it can show days and a running clock when space allows.

Count-down events can optionally repeat weekly, monthly, or yearly. Monthly dates keep their original day when possible and use the last valid day in shorter months. Optional local reminders can alert you on the event day or 1, 3, or 7 days before.

Reset an eligible date-only count-up to today from Home, with confirmation and Undo. Share an event as a local image card, import or export JSON backups manually, and switch between English, Español, and Català or follow the system language.

Automatic event backups are optional and off until you enable them. Verified JSON copies go to Downloads/CountAway by default on Android 10+, or to a folder you choose. Android 8–9 asks you to select a folder. CountAway aims to keep seven distinct verified copies when safe cleanup is available; restore events with Import.

CountAway works without accounts, ads, analytics, or an Internet permission. Event data stays local unless you choose to save a backup through a document provider, which may sync that file independently.
